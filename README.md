Python Activity-Based Learning Assignment
About the Project
This project contains ten Python case studies. Each case study
demonstrates how Python programming concepts can be applied to
practical, real-world-style problems. The programs cover calculations,
data processing, validation, and simple management systems.
Case Studies
1. Product Billing and Discount Calculation -- Calculates
   product-wise amounts, total bill, discount, and final payable
   amount.
2. Bank Transaction Management -- Processes deposits and
   withdrawals and displays account totals.
3. Student Performance Analysis -- Calculates student averages,
   improvement, and performance categories.
4. Timetable Conflict Detection -- Identifies overlapping classes
   scheduled on the same day.
5. Duplicate and High-Value Transaction Detection -- Finds repeated
   transaction IDs and transactions above a specified amount.
6. Student Feedback Sentiment Analysis -- Counts positive and
   negative words to classify feedback.
7. ATM Menu-Driven Banking System -- Provides deposit, withdrawal,
   balance enquiry, and transaction history options.
8. Student and Subject Marks Matrix Analysis -- Calculates
   student-wise totals and averages, along with subject-wise averages.
9. Canteen Order and Stock Management -- Processes food orders,
   calculates bills, and updates available stock.
10. Student Record Validation -- Checks duplicate student IDs and
    validates marks and attendance values.
Python Concepts Used
The case studies demonstrate:
- Variables and basic data types
- Input and output statements
- Arithmetic and comparison operators
- Conditional statements (if, elif, and else)
- for and while loops
- Lists and list methods
- Tuples and tuple unpacking
- Dictionaries
- Nested lists and matrix processing
- String methods and string processing
- Built-in functions such as len(), sum(), and range()
- Membership testing and data validation
- break and continue control statements
Requirements
- Python 3.x
- IDLE, Visual Studio Code, PyCharm, or another Python editor
- A terminal or command prompt

How to Run the Programs
1. Install Python 3.x on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal or Python editor.
4. Navigate to the programs folder.
5. Run the required Python file using:
python filename.py
For example:
python case_study_01_product_billing.py
Some programs ask the user to enter values, while others use sample data
already written in the code.
Learning Outcomes
After completing these case studies, students can practise:
- Writing programs using loops and conditional statements.
- Organizing and processing information with lists, tuples, and
  dictionaries.
- Performing calculations and validating user input.
- Working with strings and two-dimensional lists.
- Applying Python concepts to practical problem-solving tasks.
Conclusion
These ten case studies demonstrate the practical use of Python programming concepts in different problem areas, including billing, banking, student performance, timetable checking, transaction monitoring, feedback analysis, ATM operations, canteen stock management,and student record validation. Together, they provide practice in basic Python programming, data structures, decision-making, iteration, and problem-solving.
